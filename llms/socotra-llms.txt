# Socotra

> Socotra is a cloud-native insurance core platform (Connected Core / Insurance Suite) that lets carriers, MGAs, and program administrators configure, launch, and operate insurance products across any line, geography, or distribution channel. It exposes a broad tenant-scoped REST API (722 operations) plus first-party SDKs, CLIs, a schema-driven React UI SDK, and a hosted MCP server for AI agents. Backed by 8VC and Insight Partners.

## APIs
- [Socotra Insurance Suite API reference](https://docs.socotra.com/docs/api): 722 operations across policy, billing, claims, quotes, accounts, contacts, producers, work management, documents, accounting, configuration, events/webhooks, and search.
- [OpenAPI definition](https://docs.socotra.com/openapi/socotra-openapi.json): OpenAPI 3.0.1, 629 component schemas.

## Authentication
- [Authentication profile](authentication/socotra-authentication.yml): bearer access token from POST /auth/users/tokens using business-account credentials; OAuth 2.1 for interactive/agent access; SAML/OIDC SSO.
- [API conventions](conventions/socotra-conventions.yml): tenant-scoping via {tenantLocator}, locator ids, offset/count pagination with ListPageResponse, X-Idempotency-Key on migration ops.
